# ⚖ Compliance Monitor

Веб-приложение для мониторинга изменений законодательства. Разработано для ежеквартального процесса ознакомления руководителей департаментов с изменениями нормативно-правовой базы.

## Возможности

- **Обзор (дашборд)** — статистика, срочные изменения, прогресс ознакомления по департаментам
- **Опубликованные НПА** — вступившие в силу изменения с критичностью, санкциями, влиянием
- **Проектные НПА** — законопроекты с вероятностью принятия
- **Комментарии** — все ознакомления и комментарии в одном месте
- **Добавление записей** — юристы добавляют новые изменения через форму
- **Фильтры** — по департаменту, критичности, поиск по тексту
- **Экспорт отчёта** — выгрузка текстового отчёта с комментариями
- **Хранение данных** — комментарии и ознакомления сохраняются в `localStorage`

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите файлы (`index.html`, `styles.css`, `app.js`, `data.js`)
3. Перейдите в **Settings → Pages**
4. В разделе **Source** выберите ветку `main`, папку `/ (root)`
5. Сохраните — приложение будет доступно по адресу `https://<ваш-логин>.github.io/<название-репо>/`

## Обновление данных (для юристов)

**Способ 1 — через форму в приложении:**
Нажмите кнопку **⊕ Добавить изменение** в левой панели.

**Способ 2 — редактирование файла `data.js`:**

Добавьте запись в массив `PUBLISHED_CHANGES` или `DRAFT_CHANGES`:

```javascript
{
  id: "pub-6",           // уникальный ID (pub-N или dft-N)
  num: 6,                // порядковый номер
  category: "Трудовое право / ...",
  title: "Краткое название изменения",
  summary: "Подробное описание...",
  normAct: "ФЗ от ... № ...",
  effectiveDate: "2026-10-01",   // формат YYYY-MM-DD
  sanctions: "Штраф...",
  criticality: "Средняя",        // Высокая / Средняя / Низкая / Отсутствует
  impact: "Влияние на компанию...",
  mitigation: "Что нужно сделать...",
  deadline: "До 01.10.2026",
  departments: ["ФЭД", "КД"],   // массив департаментов
  status: "Учесть в работе"      // или "Для информации" / "Мониторинг"
}
```

## Следующий квартал

Для обновления на Q2 2026:
1. Обновите константу `QUARTER` в `data.js`: `const QUARTER = "Q2 2026";`
2. Добавьте новые записи в массивы данных
3. При необходимости перенесите проектные НПА в опубликованные

## Структура файлов

```
├── index.html    — разметка приложения
├── styles.css    — стили (тёмная тема)
├── data.js       — данные (НПА, изменения) — редактируется юристами
├── app.js        — логика приложения
└── README.md     — документация
```

## Compliance best practices, реализованные в приложении

- ✅ Трёхуровневая шкала критичности рисков
- ✅ Фиксация факта ознакомления с указанием автора и времени
- ✅ Возможность отметить вопросы/риски отдельным типом комментария
- ✅ Прогресс-трекер ознакомления по департаментам
- ✅ Раздел проектных НПА с вероятностью принятия (риск-ориентированный мониторинг)
- ✅ Раздел «Митигация риска» для каждого изменения
- ✅ Экспорт отчёта для документирования процесса
- ✅ Сроки адаптации и дедлайны по каждому НПА
